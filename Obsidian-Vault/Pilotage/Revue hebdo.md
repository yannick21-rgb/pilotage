# Revue hebdomadaire — dimanche, 30 minutes

## Les 3 questions

1. **Qu'est-ce qui existe maintenant qui n'existait pas dimanche dernier ?**
   (une capture, une vidéo, un commit, un message envoyé, un testeur)
2. **Qu'est-ce qui m'a bloqué, et qu'est-ce que je change demain ?**
3. **Quelle est la seule action de la semaine prochaine ?**

## Le rituel

- [ ] Cocher les actions faites dans [[Cycle 1 — Orane.d]]
- [ ] Ajouter la preuve de la semaine dans [[Preuves]] (statut `fait`)
- [ ] Écrire la ligne du jour dans [[Journal]]
- [ ] Choisir la prochaine action et l'écrire dans [[Cycle 1 — Orane.d]]
- [ ] Regénérer le dashboard : `python3 ~/.hermes/scripts/pilotage.py`

## La règle

Une semaine sans preuve est une semaine ratée — même avec 20 commits.
Si la semaine a été mauvaise, on ne rajoute pas d'objectif : on réduit le périmètre.
